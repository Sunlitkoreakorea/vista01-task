# VISTA-01

짧은 영상을 보고 두 대상의 상대적 순서를 판단하는 익명 시각 과제입니다.

이 저장소에는 참가자용 정적 웹 인터페이스와 본실험형 합성 자극 24쌍이 포함됩니다. 구체적인 연구 가설, 연구자 화면, 분석 자료는 응답 편향을 줄이기 위해 별도로 관리합니다.

현재 공개본은 `1.0.0-rc1` 후보판입니다. 정답형 연습/24회 무작위 본 시행/4개 응답 범주/필수 확신도/중간 휴식/품질관리 로그를 포함합니다. 기관의 사람 대상 연구 승인과 승인된 설명문/동의서가 준비되기 전에는 실제 자료수집에 사용하지 않습니다.
